# 天堂放置單機版

這是一個可攜、獨立的單機遊戲資料夾。所有遊戲程式、樣式與素材都已包含在內；不需要安裝套件或連網。

## 遊玩

雙擊 `開始遊戲.cmd`。瀏覽器開啟後即可建立角色與遊玩。請保持出現的命令視窗開著；關閉它會停止本機遊戲入口。

角色資料儲存在每一位玩家自己的瀏覽器中。同一台電腦、同一個瀏覽器會繼續讀取原本進度；換電腦或清除瀏覽器資料前，請使用遊戲內的匯出存檔功能備份。

## 修改遊戲

- `index.html`：畫面結構、按鈕與分頁。
- `css/style.css`：主要視覺、版面與介面樣式。
- `js/00-data.js`：職業、怪物、道具、初始數值與存檔邏輯。
- `js/01-drops-config.js`：掉寶與怪物相關設定。
- `assets/`、`public/assets/`：角色、地圖、圖示、音效等素材。

修改前建議先複製整個資料夾當備份；每次修改後，關閉並重新開啟遊戲即可載入新版內容。

## 之後分享給朋友

目前這是「單機版」：朋友各自下載完整資料夾並執行 `開始遊戲.cmd`，每個人有自己的角色與存檔，不會互相影響。

若要讓所有朋友共用角色、交易、排行榜或即時聊天，需要另外建立伺服器與帳號系統；目前的本機存檔不會自動同步到他人的電腦。
